# 續約通知與房間列表到期提示（2026-11-03）

使用者已驗收測試站，確認同步正式站、公開唯讀站及 Pages Demo：通知圖片加入續租／不續租回覆、考慮中或租屋問題可討論、續約及退租點交安排、結尾感謝。開頭使用「這段期間」，適用多年租約；不設回覆期限。房號與到期日使用所選房間已儲存資料。

圖片以實際字寬換行，再由內容計算高度，保留原綠白樣式與 PNG 下載。產生預覽不呼叫寫入 API、不自動聯絡房客。

房客頁左側房間列表顯示紅框及「即將到期／已到期」文字；選中狀態仍保留紅框與高對比標籤。手機列表可換行，所有可見文字至少 16px。空房或缺少日期不顯示到期提示。

沿用房屋概況的台北當日及日曆月判定：已過日期為已到期、含今日至一個月內為 urgent、至三個月內為 soon。將原判定函式移至房客共用程式，由概況與列表共用，未改既有界線。

測試驗證實際 Vue 房間列表的三個月／一個月邊界、已到期、當日、空房、選中標籤，以及 Canvas 完整文案、自動換行、內容高度、不含回覆期限與零來源寫入。另沿用工作區、原房客編輯、地址及唯讀回歸。

本輪把已驗收 UI 同步至正式、公開與 Demo；Demo 維持假個資／照片與原數值快照，公開站維持資料文字呈現及全部寫入拒絕。無 Apps Script、試算表、照片或權限更新。
