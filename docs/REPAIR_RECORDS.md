# 修繕紀錄（2026-11-15）

入口：更多 → 修繕紀錄。管理者可新增、編輯、作廢；房東唯讀與 Demo 只供查看。按年份／房號或公共區域／項目與備註搜尋，20 筆一頁。日期、房號／區域、項目、金額必填，允許 0 元。選填備註、廠商、聯絡方式、照片與既有支出關聯。

## 資料與金額

每個房產資料庫的可選分頁「房產修繕紀錄」獨立保存，不依房客身份。查詢不建分頁、不寫資料；首次管理者明確儲存時建立。不改租金、電費、押金、實收、每月支出或請款小計。修繕合計排除作廢，僅供維護統計。

選擇既有支出只保存關聯，不建立或修改支出。關聯當下必須同房產、有效、金額相符，且不能被另一有效修繕重複關聯；支出有不明操作時暫停關聯。支出本身日後有變更，不自動改修繕歷史。可於修繕編輯取消或更換關聯。

房間「房間維護整修紀錄」只顯示該房列表與詳情；舊維護文字以原文保留，沒有自動拆分、搬移或刪除。房間歸屬依歷史房號保存；若日後修改房號，可在集中修繕頁調整紀錄歸屬。退租不清除獨立修繕表。

## 照片

每次最多三張，每筆保留最多十張；瀏覽器縮圖至最大 1600px，優先 WebP，不支援時使用實際 JPEG，後端驗證格式與大小。檔名使用台北上傳日期加資料夾內連號。路徑：既有房產照片根目錄／紀錄首次建立年份／04.房產修繕紀錄／月份。修改紀錄日期不移動舊照片；檔案不刪除、不改分享權限。照片僅按查看時讀取，支援換張與縮放。

## 操作保護

管理者寫入、簽章與房產範圍檢查、輸入驗證、預覽後確認、版本衝突、操作識別與寫入前後逐列核對。明確未寫入的錯誤保留草稿可修改；結果不明保留草稿與圖片並禁止重送，只能讀回核對。作廢保留資料與照片。
