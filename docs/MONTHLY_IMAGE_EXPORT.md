# 每月紀錄圖片匯出（2026-11-15）

每月帳務與每月支出上方提供「匯出本月紀錄」。預設沿用目前工作表年月，可在預覽內切換。以既有讀取 RPC 產生租金與支出 PNG，可逐張下載或下載 ZIP。大量紀錄分頁、每頁重複表頭與頁碼，合計只在最後一頁。不含請款狀態、收據照片；不改原請款功能。

租金欄位為房號、房客、完整匯款日期、已登記匯款金額、帳號後五碼、核對狀態。零與未知分開；不以應收推算，未拆分押金顯示未知。相同收款 ID 合併成一列，避免同筆匯款重複加總；合併資料不一致時阻擋。已核對且金額已知才納入已核對合計。

支出排除作廢、保留單價／數量／小計，總計不另加入修繕紀錄。遇待核對支出操作阻擋匯出。圖片依暖色／鼠尾草採實色底，文字換行；匯出時間使用台北時間。

只在使用者開啟時查詢，不新增月份、不儲存帳務、不讀照片、不更動資料；blob URL 關閉時釋放，沒有個資持久化。此功能不需 GAS 更新。共享介面同步正式、測試與唯讀 Demo；Demo 沿用去個資資料來源。
