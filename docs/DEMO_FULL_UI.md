# Demo 完整介面與唯讀操作

使用者於 2026-10-24 明確確認：Demo 要與正式站使用相同元件及版面，不因唯讀身份隱藏管理元件。無法寫入的操作完整顯示並停用；篩選、切頁、圖表、圖片及通知預覽保持可用。依資料狀態才出現或點擊才展開的區塊，仍沿用正式站規則。

## 建置方式

`public/` 的共用介面保持與正式版一致。只在 `scripts/build-pages-demo.cjs` 產出的獨立靜態目錄調整呈現：

- 管理操作由「隱藏」改為「顯示、停用、標示無法寫入」。
- 房產設定入口可開啟查看；Logo 上傳入口顯示但停用。
- 登出按鈕保持原位置，展示版停用，不提交表單。
- 年度帳務檢視使用正式年度模式的初始選擇，預設當月；不顯示正式站本來就已取消的舊初始化控制。

不把 Demo 身分升成管理者。Session 仍是 viewer/canWrite:false；輸入保持唯讀、選項及上傳不可改。瀏覽器 API 在本機回應，寫入／未知 API 仍拒絕，沒有正式來源連線、憑證或資料持久化。正式站與一般檢視者的權限規則不變。

## 數值更新

私人既有匯出流程以 GET 取得正式數值後，使用嚴格白名單去除個資。2026-10-24 本次快照包含 15 間房、2026 年 1～12 月、180 筆帳務及 90 筆電表；未來預排保留 planned/unknown 狀態，不捏造已收現金，也不把它列為本期收入。

Demo 的姓名、電話、地址、租約與照片繼續使用假資料。數字是本次快照，不是即時 Google 連線。正式與公開站資料庫均未被這個流程修改。

## 驗證

對實際發布產物測試：完整管理按鈕可見且停用、房產／Logo 元件可見、對帳視窗可讀、唯讀欄位、登出不送出、各月份及每個數值與 null/0 保持一致、假個資、無 API／圖片預載外連、所有寫入與未知 API 拒絕。原純假資料互動測試、一般 viewer 隱藏寫入控制的測試仍維持，證明正式權限政策沒有被展示設定改動。
