# Demo 與正式版同步

共用介面功能（欄位、身份選項、互動、版面）修改時，同步正式版與 Demo，並更新對應假資料和驗證。兩個部署使用各自的資料來源；不把正式連線設定、帳號名單、金鑰、資料或 Apps Script 正式入口複製到公開展示。

身分改為「一般／學生／管理人」radio，預設一般。保留既有學生值；房間卡與房客頁顯示學生／管理人標籤。房客身份與網站登入角色分開。Demo 的選單維持停用、寫入仍被拒絕；不能為展示功能而開放儲存。

更新範圍：

- 修改 `public/google-tenants.html` 與共用首頁後，執行 `scripts/build-native-workspace.cjs` 產生 native 元件及樣式，不手改生成檔。
- `demo/pages-demo.js` 提供所有 Demo 資料與本機 API，更新功能時同步加入純假資料範例；API 不得轉送到正式服務。
- 執行 `npm run build:pages` 與 `npm run test:pages`，確認身份選項、學生／管理人範例、唯讀欄位及拒絕寫入，且私人服務沒有收到任何請求。
- 保留 Demo 自己既有的房型、初始電表、簽約日及每月 10 日參考日，不用整個舊版本覆蓋新版本。
- 正式資料庫的歷史保護、部署設定與授權名單依其私有來源管理；這些不屬於公開 Demo 同步項目。
