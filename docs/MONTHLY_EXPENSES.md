# 每月支出唯讀展示（2026-10-28）

與驗收通過的每月支出畫面同步：年份／月份／重新讀取／新增支出底部對齊，欄位包括日期、項目、單價、數量、金額、收據、備註及操作。日常現金支出獨立列示，不併入租金、電費或收租統計。

本 Demo 的支出及收據全部為虛構，與既有正式租金／電表數值快照分開。每月示範合計 1,103 元，另有作廢樣本不列合計。可點「檢視明細」查看停用的欄位及上傳／儲存／作廢控制，也可點收據開啟 Lightbox、切換與放大；圖片只在點擊時於瀏覽器生成示意圖。

新增、修改、作廢、儲存及上傳都停用；直接呼叫寫入 API 也會拒絕。沒有 Google／正式 API 連線、真實支出、收據檔案 ID 或照片，沒有 localStorage 寫入。原有租金／電表數值快照保持不變。
