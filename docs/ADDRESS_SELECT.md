# 房客／保證人戶籍地址連動選單（2026-11-01）

使用者確認兩處一起修改並執行，先發布驗收站。

## 行為

- 可編輯的地址拆為縣市、鄉鎮市區、詳細地址。地區依縣市連動；切換縣市清除舊區域選擇，保留詳細地址，選完區域才能儲存。
- 寬度足夠時三欄同列，空間不足自動換行。維持原表單間距及至少 16px 文字。
- 選單只管理畫面草稿。按「儲存全部修改」時組回原本完整字串，仍使用 registeredAddress／guarantorAddress 原欄位與原版本檢查，不新增後端欄位或 API。
- 台／臺舊寫法能辨識，初次讀取不改原文、不標記修改、不自動寫入。只有實際編輯並儲存才組合新的地址。
- 無法確定拆分的舊資料（郵遞區號前綴、舊行政區、海外或其他文字）完整保留於詳細地址並提示。單獨修改其他欄位不會把地址帶入寫入。
- 「還原全部未儲存」恢復原縣市區域與詳細地址；房客與保證人地址獨立，切換房間不沿用前一間草稿。
- 唯讀／公開查閱保留完整地址單一欄位，不提供縣市區域編輯。

## 清單來源

使用本地打包的 22 縣市及郵遞區域名稱，不執行線上地理編碼、不把地址送第三方。清單參考 [CityCountyData.json 固定版本](https://github.com/donma/TaiwanAddressCityAreaRoadChineseEnglishJSON/blob/233bff2a43ebaea28620fd996ecec23fffc74016/CityCountyData.json)，只取縣市及區域名稱，不含道路、座標、個資或外部執行程式。來源含離島及特定郵遞區域，未自行將無法辨識舊址改寫成現行行政區。

## 發布與驗收

只更新原驗收站前端，不修改正式／公開／Pages 分支，不改 Google 試算表、App Script、照片或租金。無須替換 GAS、初始化或匯入。

合成 UI 測試涵蓋兩處連動、縣市選項、台／臺舊址不自動標記、區域選項、部分選擇阻擋、批次組合字串、還原、切房與無法拆分資料保留；沿用房客整份儲存、公開唯讀及既有驗收回歸檢查。


## 使用者後續調整發布流程

使用者要求本輪地址完成後直接同步，不再等待測試站人工驗收。正式站可編輯房客與保證人地址；公開／Demo 仍顯示原完整地址唯讀。此項只改前端，不需更新 Google Web App、不搬移資料。公開站將表單外觀改為文字資料的需求另列下一輪，須確認後才執行，本輪未修改該呈現。
