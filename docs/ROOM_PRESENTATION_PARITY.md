# 房間畫面一致性（2026-11-16）

正式與房東唯讀入口使用同一套房間卡片、搜尋／狀態／租約篩選及詳情彈窗。停用唯讀入口舊版的清單加內嵌詳情呈現。租補標籤與雙色主題共用。

只變更呈現模式；RentalPublic、唯讀傳輸、資料投影、write directives 與後端寫入拒絕保持獨立。房東仍不能修改，沒有 GAS 或資料變更。回歸測試使用實際唯讀頁掛載、共享篩選與卡片開彈窗，並確認查閱只發出 get 請求。

租補標籤沿用 student-tag 的完整尺寸與字重，僅以內框區分；房客彈窗改置中，移除 modal-active 導致背景列表縮成 240px、隱藏租金日期與縮小字體的舊樣式。唯讀欄位不記錄可編輯草稿，仍保留讀取中的切頁保護。
