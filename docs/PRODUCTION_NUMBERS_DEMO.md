# 正式數值／假個資 Demo

使用者於 2026-10-24 授權：正式管理站使用原真實個資；使用者後續更正並確認：公開唯讀站也保留真實個資；Pages Demo 與驗收站使用假個資，帳務數值取自正式資料。

`demo/production-numbers.json` 是嚴格白名單的數值快照，不是即時連線。包含實際期別、房號、租金、電費、電表、來源已知金額與未知狀態；沒有原姓名、電話、地址、備註、銀行尾碼、合約／照片連結或金鑰。資料缺失保留未知，不用示範公式補造未建立的月份。

頁面個資與照片繼續使用原虛構範例，私人寫入及外部 API 全部拒絕。來源簽約報表的押金與簽約實收分開呈現；實際帳務與核對仍以正式管理站為準。

更新由管理者從私人數值匯出流程產生新快照，經白名單及數值核對後同步本檔，再建置及通過 Pages 部署檢查。禁止將原始試算表或個資 JSON 放入本倉庫。

共用介面同步對帳視窗、抄表與通知、續約圖片、房產入口、標籤間距及報表左右排版。保留本倉庫自己的 Pages workflow、房型與初始電表測試及純虛構備用 fixture。
