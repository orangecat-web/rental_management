# 每月支出：整月請款狀態

2026-11-14 使用者確認：在支出列表小計下方，以整個月份為單位增加「未請款／已請款」，預設未請款；已請款必須填日期。

## 使用

每月支出 → 選擇年度／月份 → 小計下方「本月請款」。選已請款後填寫有效請款日期，再按儲存請款狀態；未請款不保留日期。狀態依房產、年度、月份隔離。

日期前端會檢查並將焦點放回缺漏欄位，Worker 檢查必填格式，Google 後端再檢查有效日曆日期。重新讀取後保留已儲存資料；未儲存修改會阻擋切換年月及離頁。儲存結果不明時保留輸入並讀回核對，不自動重送。

請款狀態獨立於支出明細及金額。標記已請款不會改變小計、收據、房租、實收、押金或銀行紀錄。已請款後新增、修改或作廢本月支出，保留原狀態與請款日期，顯示原請款小計並提醒重新核對。

## Google 更新

正式專案以 production/XingwuProduction.gs.txt 整份替換原 XingwuProduction.gs；測試專案以 acceptance/RentalAcceptance.gs.txt 整份替換原 RentalAcceptance.gs。保留其他程式檔、網址、金鑰與指令碼屬性，儲存並將各自原 Web App 更新為新版本。

不用執行任何函式、準備欄位、初始化或重新匯入。首次明確儲存請款狀態時，才在該房產資料庫建立可選的「支出月份請款」分頁。舊月份讀取時顯示預設未請款，不回填、不變更舊支出。

若尚未安裝新版後端，頁面會提示更新並停用儲存。網站發布不代表 Google Web App 已更新，本環境沒有 Google 部署登入。

## 資料與權限

可選分頁欄位：年度、月份、請款狀態、請款日期、請款時小計、支出版本、版本、最後操作 ID、更新時間。後端按當時有效支出計算請款小計，不接受瀏覽器傳入金額。版本包含月內支出變動，避免用舊畫面覆蓋新請款紀錄；寫入前再核對目標位置、公式與合併格，寫入後讀回驗證。

只有管理者可儲存，公開與檢視入口均維持唯讀；房產範圍由既有驗證路由決定。月份請款有獨立寫入狀態，結果待核對時阻擋同月重送及支出變更。資料未查明前不自動重試或清除標記。

Demo 同步唯讀介面；去個資快照只允許請款狀態、日期、請款小計及變動／待核對布林值，不包含原始版本或操作 ID。測試數值匯入會保留來源月請款狀態，重建測試關聯與版本，仍只寫獨立測試副本。

## 驗證

合成測試涵蓋預設未請款、日期缺漏／無效日期、整月保存與重新載入、年月及房產隔離、管理者／檢視者權限、小計不變、支出異動提醒、過期版本拒絕、重複請求不重寫、不明結果讀回、寫入中斷阻擋、Demo 拒絕寫入及無個資快照。所有測試均未寫入正式資料。
