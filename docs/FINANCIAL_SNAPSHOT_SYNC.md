# 正式數值同步／虛構人物

2026-11-14 使用者要求作品 Demo 的帳務與正式站一致，並明確納入押金與支出數值。姓名、電話、地址、證件、合約、照片及自由文字仍為假資料；本次只讀正式來源。

作品保持靜態網站，每次發布前取得當時的去個資快照；既有 Pages workflow 另每小時排程刷新，排程實際時間依 GitHub 佇列而定，不是即時推播。頁首顯示快照取得時間。來源不可用或白名單驗證失敗時停止發布，既有已部署版本保留。

同步年度月份、租金、電費、應收、實收、核對狀態、欠款與溢收、電表與統計，並保留 0、未知與未來預排的差別。月帳及收款統計沿用正式站已排除押金的投影，不再二次扣除押金。

押金同步各租約的數值、結算小計及已結清狀態；人物、事件 ID、租約 ID、說明與其他扣款原因改為展示用內容。支出同步日期、單價、數量、金額、作廢狀態及收據張數；項目、備註與收據像素均為虛構。所有圖片僅在點選時由本機示意繪圖產生，不讀正式 Drive。

`scripts/demo-numbers-schema.cjs` 同時負責匯出白名單與整份快照驗證，不允許姓名、自由文字、銀行尾碼、原收據／事件／文件 ID 或網址進入快照。`demo/production-numbers.json` 保存已核驗的數值；發布工作再刷新來源，避免只更新介面卻沿用舊帳務。

測試站仍使用自己的 Google 資料庫，可修改。其數值匯入與此靜態 Demo 的發布流程分開，不使用正式寫入金鑰，也不將測試修改回傳正式站。
