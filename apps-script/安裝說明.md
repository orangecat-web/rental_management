# 第一部分：Google 設定與測試

## 目前可用範圍

網站 Demo：房客編輯、租約與合併通知群組、學生標籤、介紹/備註/維修紀錄、每月帳務、抄表與示意照片、匯款截圖、單戶直式 JPG、整表遮蔽 JPG。所有展示資料都是虛構，保存於 localStorage。

Google 存取層：已提供基本資料讀取、基本資料指定欄位寫回、月份資料讀取、指定人工欄位寫回，以及依年份/月分資料夾列出與讀取私人照片。測試使用 mock；尚未連線實際帳號。

重要：安裝 Apps Script 後，「Google 串接設定」中的讀取及寫回操作會操作設定的 Google 檔案。其他管理頁仍是本機 Demo，不會因為打開 Apps Script 就自動同步整份資料。Google 基本資料編輯 API 已備妥，尚未接到完整管理表單；月分資料可在串接設定頁逐房更新。完整 Google 工作流、照片ID寫回帳單、雲端通知與租約新增/退租同步，須在取得測試副本後繼續整合，不能視為已完成正式系統。

## 先準備四個位置

1. 房客基本資料 Google 試算表的副本。保留原欄位，記下分頁名稱。
2. 每月帳務 Google 試算表的副本。每月一頁，名稱例如 2026-09、2026-10、2026-11。保留現有公式。
3. 電表照片根資料夾：2026 / 11 / 401_1101.jpg。
4. 匯款截圖根資料夾：2026 / 11 / 原有檔名。此階段匯款照片先手動對應，未擅自假設一圖一房；電表命名規則不強制套在匯款截圖上。

四者一般存取權設為受限制，指定分享給你與房東。讀取照片需該使用者有該資料夾及檔案權限。編輯試算表需編輯者權限。不要提供密碼/驗證碼。

網址 /spreadsheets/d/【這一段】/edit 是試算表 ID，/drive/folders/【這一段】 是資料夾 ID。

## 安裝（先用副本）

1. 到房客測試試算表：擴充功能 → Apps Script。
2. 將 Code.gs 貼入程式碼；新增一個 Config.gs，貼入套件中的同名檔內容。
3. 編輯 Config.gs：填兩份試算表 ID、基本資料分頁名稱、兩個照片根資料夾 ID，以及你與房東的 Google 信箱。
4. 新增 HTML 檔案 Index，貼上 Index.html 全部內容。
5. 專案設定顯示 appsscript.json，依套件 manifest 設定時區及權限。若已有部署設定請保留，而非盲目取代。
6. 先執行 checkConfiguration，檢查授權畫面上的程式及權限。這是你自己建立的程式；若無法辨識來源或權限不符，先停止核對。
7. 部署 → 新增部署作業 → 網頁應用程式；執行身分選「存取網頁的使用者」，存取選項要求登入 Google（實際選項依帳號而定）。每個伺服器入口仍核對 Config.gs 指定信箱，不代表所有登入者都能讀資料。
8. 先由你開啟部署 URL，在 Google 串接設定測試讀取。再以房東帳號登入與授權，確認兩邊皆能讀取及更新測試分頁。
9. 先改一筆本期讀數或收款日期，查看原表更新及公式結果；另一分頁的舊資料應被指紋檢查拒絕寫入。

若 Session.getActiveUser().getEmail() 空白，後端拒絕存取；不可移除驗證作為修正。先核對執行身分與 Google 權限。不要改成公開匿名且用擁有者身分執行。

## 支援的現有表頭

房客：房號、居住者（或簽約人）、連絡電話（或聯絡電話）、起租日、到期日、同居人、同居人電話、緊急聯絡人、聯絡人電話、目前房租（或房租）、基本介紹、備註、房間維護整修紀錄。

帳務：房號、簽約人、房租、前期抄表日期、前期電表、本期抄表日期、本期電表、需繳電費（或電費）、應繳金額、轉帳日期（或收款日期）。目前若有兩個同名「應繳金額」，讀第一個，需依副本實際表頭再核對。

Google 寫回只改本期電表、本期抄表日期、收款日期；若目標為公式或合併格會拒絕，不覆蓋公式。本期減上期及乘5仍由原表公式計算。

## 通知與照片

Demo 使用清楚標示的示意照片；正式照片留在 Drive。上期只帶讀數與日期，不複製上期照片。

單戶通知：只有所選承租戶房間資料；504/505 同戶以帳單群組合併。整表模式：其他戶直接以空白遮蔽區繪製，不畫入原姓名/金額。JPG 為扁平影像。畫面上不會自動傳 LINE，需預覽並下載後自行傳送。

通知應繳金額是本期租金+電費，不含前期欠款、預收款抵扣或退款。

## GitHub Pages

- dist 為靜態 Vue 網站，可部署到 Pages；.github/workflows/pages.yml 已準備。
- GitHub 建立 repo，推送原始碼後，到 Settings → Pages，Source 選 GitHub Actions。
- Pages 版只部署 dist；不會部署私人 Config.gs。套件中的 Config.gs 為空白範本，不要將填過的正式 Config.gs 推到公開倉庫。
- Pages 無法呼叫 google.script.run。真正的 Google 串接版目前使用 Apps Script 網頁 URL；若正式前端要放 Pages，下一步需改成 Google OAuth + Sheets/Drive API，或授權 API 後端。
- 網站公開不代表資料公開；登入與資料授權仍在 Google 端驗證。
- 不要把真實房客、照片、匯出通知 JPG 或 OAuth token 寫進 repo、dist、前端環境變數。

## 驗證狀態

Vue 模板編譯、JS 語法及業務測試通過；Google API 使用 mock 驗證帳號限制、公式保護、欄位更新及衝突拒絕。瀏覽器預覽環境仍無法啟動，因此尚未完成實際照片上傳、Canvas JPG 下載與手機外觀驗證。Google 實際授權及試算表讀寫亦待測試副本連線。
